# M7.1 persistence foundation policies

Status: accepted implementation decision for Kanban task `t_b5d562f3`.

DECISION | Wheeljack | Version handling before M7.2 recovery and UI | Accept only exact `1.0.0` as editable today. A higher major returns raw original bytes as a read-only, upgrade-required result. A `1.x` future minor is rejected unless a named registry entry supplies a defaultable pure migration; no future-field meaning is inferred. | The normative schema is exact `1.0.0`; the spec permits future-minor loading only where a defaultable migration is defined, and none exists yet. | A later format card must add a deterministic migration function and report before accepting a new minor. No arbitrary invalid input is migrated.

DECISION | Wheeljack | Validation error boundary | Validate the full current structural contract and shared runtime semantics before encoding, importing, or applying an imported replacement. Reject invalid inputs without repair. | Structural and cross-reference errors must not create a persistence side channel that diverges from M4/M5/M6 command semantics. | Invalid input leaves the command store's document, revision, undo, and redo unchanged. Browser drafts remain allowed to be temporarily incomplete (for example M9 setup) but cannot be saved until valid.

DECISION | Wheeljack | FTL member removal and persistence | Treat stale FTL references created by legitimate M5 editing as a working-draft blocked state, not as persistable data. Playback continues to report its existing invalid-FTL error; explicit save/import requires strict current FTL validity. | Silent removal or conversion would lose authored formation intent, while persisting an invalid snapshot would violate the normative format. | Writers must repair or explicitly convert the FTL before save. M7.2 recovery must preserve raw bytes if it ever encounters an older/stale draft source.

DECISION | Wheeljack | Explicit-file permissions and ancestry | A direct overwrite is attempted only for an active, permission-granted File System Access handle. Save As may invoke the picker from a user gesture; otherwise it dispatches a new UTF-8 `.freeform` download. Imported raw bytes are preserved separately from working state; handles are never serialized. | Browser permissions are revocable and a browser working copy is not proof of an explicit-file write. | Denial, cancellation, and write/download failures do not report success and callers must retain dirty/checkpoint state. Filesystem retention/deletion is deferred.
